# Input_Data

| Path | Contents | Origin / license |
|---|---|---|
| hld/HLD_CruiseControl_v1.0.pdf, v1.1.pdf | Cruise-control AUTOSAR HLD, two versions | SYNTHETIC. Generated by Code/generate_synthetic_hld.py. Own work. |
| specs/ | JSON definitions used to generate the PDFs | Own work |
| ground_truth/ | Planted inconsistencies, labelled entities, revision diff | Own work |
| test_questions.json | Evaluation questions with expected answers | Own work |
| manifest.json | Registry the notebook reads (file, version, status, source, license) | Own work |

The HLDs are synthetic stand-ins because real project HLDs are confidential. Scores on synthetic data
are likely optimistic compared with real documents.

To add a public document (for example an AUTOSAR specification): copy the PDF into hld/, add an entry to
manifest.json with its source URL and license, and cite it in the report and the declaration.
